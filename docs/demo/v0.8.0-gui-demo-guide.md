# GeoTaskShield v0.8.0 GUI Demo Guide

This guide is for demonstrating the Phase 9 GUI export workflow included in the `v0.8.0` release package.

## Launch the GUI

From a local debug build:

```powershell
out\build\x64-debug-qt\GeoTaskShield\GeoTaskShieldGui.exe
```

From the Windows release package, run:

```powershell
GeoTaskShieldGui.exe
```

   - Show the central map canvas with workers, exposed locations, tasks, and assignment lines after a simulation run.
   - Show the right metrics panel and bottom log panel.

2. `Batch Results` tab

   - Show the left CSV/filter/metric/export controls.

   - Click `Preview Markdown`.

## Batch Results Demo Flow

1. Open the `Batch Results` tab.
2. Click `Open CSV`.
3. Select `phase5_batch_results.csv`.
   - In the source tree it is at the repository root.
   - In the release package it is copied next to the executables.
4. Use the privacy filter to select one mechanism, such as `Grid Privacy`.
5. Use the algorithm filter to select one algorithm, such as `Nearest Greedy`.
6. Change the metric selector, for example:
   - `completionRate`
   - `privacyUtilityRatio`
   - `fairnessIndex`
   - `averagePrivacyLoss`
7. Click table headers to sort rows.
   - Numeric columns sort numerically.
   - Text columns sort alphabetically.
8. Select a table row and inspect the detail panel.
9. Click `Export Filtered CSV`.
   - Save the file as `filtered-batch-results-v0.8.0.csv`.
   - The export uses the current privacy and algorithm filters.
   - The exported file keeps the Phase 5 batch CSV header.
10. Click `Preview Markdown`.
    - Confirm the preview includes the report title, result table, row count, and best privacy-utility summary.
11. Click `Export Markdown`.
    - Save the file as `batch-results-report-v0.8.0.md`.

## Example CSV

The release package includes `phase5_batch_results.csv`. It uses the current Phase 5 header:

```text
scenario,workers,tasks,grid_size,k,epsilon,privacy,algorithm,completed_tasks,total_tasks,completion_rate,average_moving_distance,total_reward,average_privacy_loss,algorithm_runtime_ms,user_load_stddev,fairness_index,privacy_utility_ratio,timeout_rate
```

The loader also accepts selected aliases used by later analysis tools:

| Supported aliases | Internal field |
|---|---|
| `average_moving_distance`, `average_true_distance`, `averageTrueDistance` | `averageTrueDistance` |
| `algorithm_runtime_ms`, `runtime_ms`, `runtimeMs` | `runtimeMs` |
| `privacy_utility_ratio`, `privacyUtilityRatio` | `privacyUtilityRatio` |

## Release Scope

This release hardens the Phase 9 GUI export workflow. It does not add Qt Graphs, migrate tests to GoogleTest, or integrate an online LLM.
