# GeoTaskShield v0.9.0 GUI 演示指南

本文档用于演示 `v0.9.0` 发布包中的 GUI 主流程。演示重点是：

- `Simulation` tab 的默认仿真；
- `Batch Results` tab 加载、筛选、排序、导出 CSV、预览和导出 Markdown；
- `Agent Assistant` tab 使用默认 `Local rule-based` provider 做本地分析并导出 Markdown；
- `Aliyun Bailian (DashScope)` provider 只展示入口和环境变量说明，不作为主演示依赖。

本轮演示不包含异步 LLM 调用、超时控制、复杂错误提示、Qt Graphs、GoogleTest 迁移或新增算法。

## 1. 启动 GUI

### 1.1 从本地 Debug 构建启动

1. 打开 PowerShell。
2. 切换到项目根目录：

```powershell
cd D:\VS2026_Projects\GeoTaskShield
```

3. 运行 GUI：

```powershell
out\build\x64-debug-qt\GeoTaskShield\GeoTaskShieldGui.exe
```

4. 等待 `GeoTaskShield` 主窗口出现。
5. 如果窗口没有出现，先确认已经执行过 Qt Debug 构建：

```powershell
cmd /c 'call "C:\Program Files\Microsoft Visual Studio\18\Enterprise\Common7\Tools\VsDevCmd.bat" -arch=x64 && cmake --preset x64-debug-qt && cmake --build out\build\x64-debug-qt'
```

### 1.2 从 v0.9.0 发布包启动

1. 打开发布包目录：

```text
D:\VS2026_Projects\GeoTaskShield\out\package\GeoTaskShield-v0.9.0-windows-x64
```

2. 双击 `GeoTaskShieldGui.exe`。
3. 等待 `GeoTaskShield` 主窗口出现。
4. 确认发布包目录中存在这些演示文件：
   - `phase5_batch_results.csv`
   - `phase5_batch_report.md`
   - `README.md`
   - `HANDOFF.md`
   - `CHANGELOG.md`
   - `docs\demo\v0.9.0-gui-demo-guide.md`

## 2. Simulation Tab 默认仿真演示

1. 在主窗口顶部标签栏中点击 `Simulation`。
2. 不修改左侧参数面板中的默认值。
3. 确认左侧可以看到这些输入项：
   - worker 数量；
   - task 数量；
   - grid size；
   - k；
   - epsilon；
   - privacy mechanism；
   - assignment algorithm。
4. 点击左侧参数面板中的 `Run Simulation` 按钮。
5. 等待仿真完成。
6. 查看中间地图区域，确认可以看到：
   - worker 点；
   - 暴露位置点；
   - task 点；
   - assignment 连线。
7. 查看右侧指标面板，确认指标已刷新。
8. 指标面板至少应显示：
   - completed tasks；
   - completion rate；
   - average distance；
   - total reward；
   - privacy loss；
   - runtime。
9. 查看底部日志区域，确认日志显示仿真已运行并完成任务分配。
10. 建议截图保存为：

```text
simulation-tab-v0.9.0.png
```

## 3. Batch Results Tab 演示

### 3.1 打开 Batch Results 页面

1. 在主窗口顶部标签栏中点击 `Batch Results`。
2. 确认左侧有这些控件：
   - `Open CSV`
   - Privacy 下拉框；
   - Algorithm 下拉框；
   - Metric 下拉框；
   - `Reset filters`
   - `Export Filtered CSV`
   - `Preview Markdown`
   - `Export Markdown`
3. 确认右侧区域包含：
   - summary cards；
   - bar chart；
   - detail panel；
   - result table。

### 3.2 加载 phase5_batch_results.csv

1. 点击左侧 `Open CSV`。
2. 在文件选择窗口中找到 `phase5_batch_results.csv`。
3. 如果从源码目录演示，文件路径是：

```text
D:\VS2026_Projects\GeoTaskShield\phase5_batch_results.csv
```

4. 如果从发布包目录演示，文件和 `GeoTaskShieldGui.exe` 在同一层目录。
5. 选中 `phase5_batch_results.csv`。
6. 点击文件选择窗口中的打开按钮。
7. 等待表格加载完成。
8. 确认 result table 中出现多行实验结果。
9. 确认 summary cards 显示了最佳或最低指标来源。
10. 确认 bar chart 出现柱状图。

### 3.3 筛选 privacy

1. 点击左侧 Privacy 下拉框。
2. 选择一个隐私机制，例如：

```text
Grid Privacy
```

3. 等待表格刷新。
4. 查看 result table 的 `privacy` 列。
5. 确认当前可见行只包含所选 privacy。
6. 查看 summary cards，确认摘要也随筛选结果刷新。
7. 查看 bar chart，确认柱状图数量随筛选结果变化。

### 3.4 筛选 algorithm

1. 点击左侧 Algorithm 下拉框。
2. 选择一个算法，例如：

```text
Nearest Greedy
```

3. 等待表格刷新。
4. 查看 result table 的 `algorithm` 列。
5. 确认当前可见行只包含所选 algorithm。
6. 查看 detail panel，确认当前选中行的详情与表格行一致。

### 3.5 切换图表 metric

1. 点击左侧 Metric 下拉框。
2. 依次选择这些指标进行展示：
   - `completionRate`
   - `privacyUtilityRatio`
   - `fairnessIndex`
   - `averagePrivacyLoss`
3. 每切换一次，等待 bar chart 刷新。
4. 确认柱状图高度和标签随指标变化。
5. 如果当前筛选结果较少，可以点击 `Reset filters` 恢复所有行后再切换指标。

### 3.6 表格排序

1. 先看窗口下半部分的结果表格。
2. 表格最上面一行是表头行，能看到 `scenario`、`workers`、`tasks`、`privacy`、`algorithm`、`completionRate` 等列名。
3. 排序入口就在这一列表头行里，不在左侧按钮区，也不在上方柱状图里。
4. 把鼠标移动到 `completionRate` 这个表头单元格上。
5. 单击 `completionRate` 表头。
6. 观察表格行顺序变化，并观察该表头附近是否出现排序方向小三角。
7. 再单击一次 `completionRate` 表头。
8. 确认排序方向反转。
9. 如果当前筛选后只剩 1 到 2 行，排序变化可能不明显。可以点击左侧 `Reset filters`，或把 `Privacy`、`Algorithm` 改回 `All` 后再试。
10. 如需按 `privacyUtilityRatio` 排序，先看表格底部的横向滚动条。
11. 拖动底部横向滚动条向右，直到看到 `privacyUtilityRatio` 列。窗口较窄时，该列名可能显示成 `privacyUtilityRati...`。
12. 单击 `privacyUtilityRatio` 表头。
13. 确认该列按数值排序，而不是按字符串排序。
14. 如需验证文本列排序，拖动横向滚动条回到最左侧。
15. 单击 `scenario` 表头。
16. 确认文本列按字母或文本顺序排序。

### 3.7 查看单行详情

1. 在 result table 中点击任意一行。
2. 查看右侧或旁边的 detail panel。
3. 确认 detail panel 显示当前行的：
   - Scenario；
   - Workers；
   - Tasks；
   - Privacy；
   - Algorithm；
   - completionRate；
   - averageTrueDistance；
   - totalReward；
   - averagePrivacyLoss；
   - runtimeMs；
   - userLoadStdDev；
   - fairnessIndex；
   - privacyUtilityRatio；
   - timeoutRate。

### 3.8 导出当前筛选 CSV

1. 保持当前筛选状态，或点击 `Reset filters` 导出全部结果。
2. 点击左侧 `Export Filtered CSV`。
3. 在保存窗口中选择保存位置。
4. 文件名建议填写：

```text
filtered-batch-results-v0.9.0.csv
```

5. 点击保存。
6. 打开导出的 CSV 文件。
7. 确认第一行包含表头：

```text
scenario,workers,tasks,grid_size,k,epsilon,privacy,algorithm
```

8. 确认导出内容只包含当前筛选后的行。

### 3.9 预览 Batch Results Markdown

1. 回到 `Batch Results` tab。
2. 点击左侧 `Preview Markdown`。
3. 等待 Markdown 预览窗口弹出。
4. 确认预览窗口中包含标题：

```text
GeoTaskShield Batch Results Report
```

5. 确认预览内容包含：
   - 当前结果表格；
   - row count；
   - best completion rate；
   - best privacy-utility ratio；
   - lowest average privacy loss；
   - best fairness index。
6. 关闭预览窗口。
7. 建议截图保存为：

```text
batch-markdown-preview-v0.9.0.png
```

### 3.10 导出 Batch Results Markdown

1. 点击左侧 `Export Markdown`。
2. 在保存窗口中选择保存位置。
3. 文件名建议填写：

```text
batch-results-report-v0.9.0.md
```

4. 点击保存。
5. 打开导出的 Markdown 文件。
6. 确认文件内容与预览窗口一致。
7. 确认 Markdown 文件中没有 API key 或任何敏感密钥。

### 3.11 Batch Results 截图建议

建议保存以下截图：

```text
batch-results-tab-v0.9.0.png
batch-markdown-preview-v0.9.0.png
```

## 4. Agent Assistant 本地规则分析演示

### 4.1 准备 Batch Results 数据

1. 先完成第 3 节，确保 `Batch Results` tab 已经加载 `phase5_batch_results.csv`。
2. 可以保留当前筛选状态，也可以点击 `Batch Results` tab 中的 `Reset filters` 恢复全部结果。
3. `Agent Assistant` 会基于当前 Batch Results 可见行生成分析。

### 4.2 打开 Agent Assistant 页面

1. 点击顶部标签栏中的 `Agent Assistant`。
2. 确认页面顶部有 provider 下拉框。
3. 确认 provider 当前选择为：

```text
Local rule-based
```

4. 如果不是 `Local rule-based`，点击 provider 下拉框并选择 `Local rule-based`。
5. 确认页面中有自然语言输入框。
6. 确认页面中有 `Analyze` 按钮。
7. 确认页面中有两个预览区：
   - Parsed intent；
   - Markdown analysis。
8. 确认页面中有 `Export Markdown` 按钮。

### 4.3 输入分析请求

1. 点击自然语言输入框。
2. 输入以下 prompt：

```text
Compare privacy mechanisms for 50 tasks and explain completion rate, privacy utility, privacy loss, and fairness.
```

3. 检查输入框内容没有拼写错误。
4. 不需要配置任何 API key。
5. 不需要联网。

### 4.4 执行本地分析

1. 点击 `Analyze`。
2. 等待右侧或下方预览区刷新。
3. 查看 `Parsed intent` 区域。
4. 确认它展示了结构化意图，例如：
   - 原始 prompt；
   - tasks；
   - metrics；
   - compareRequested；
   - compareTarget。
5. 查看 `Markdown analysis` 区域。
6. 确认分析标题为：

```text
GeoTaskShield Agent Assistant Analysis
```

7. 确认 Markdown 结论包含：
   - Best completion rate；
   - Best privacy-utility ratio；
   - Lowest average privacy loss；
   - Best fairness index；
   - Next Experiment Suggestions。
8. 确认分析内容来自当前 Batch Results 数据，而不是重新运行仿真。
9. 建议截图保存为：

```text
agent-assistant-local-v0.9.0.png
```

### 4.5 导出 Agent Assistant Markdown

1. 点击 `Export Markdown`。
2. 在保存窗口中选择保存位置。
3. 文件名建议填写：

```text
agent-assistant-analysis-v0.9.0.md
```

4. 点击保存。
5. 打开导出的 Markdown 文件。
6. 确认文件包含：
   - parsed intent；
   - key conclusions；
   - next experiment suggestions。
7. 确认文件中没有 API key。

## 5. Optional DashScope Provider 入口确认

这一部分只确认入口和配置说明，不作为主演示依赖，不要求现场调用在线模型。

### 5.1 确认 provider 入口存在

1. 打开 `Agent Assistant` tab。
2. 点击页面顶部 provider 下拉框。
3. 确认下拉框至少包含：
   - `Local rule-based`
   - `Aliyun Bailian (DashScope)`
4. 选择 `Aliyun Bailian (DashScope)` 只用于确认入口存在。
5. 不要在截图、文档或报告中展示真实 API key。
6. 演示完成后，建议切回 `Local rule-based`。

### 5.2 说明环境变量

如果需要启用真实 DashScope provider，需要在运行 GUI 前设置环境变量：

```powershell
$env:DASHSCOPE_API_KEY = "<your DashScope API key>"
$env:DASHSCOPE_MODEL = "kimi-k2.5"
$env:DASHSCOPE_BASE_URL = "https://dashscope.aliyuncs.com/compatible-mode/v1"
```

说明要点：

1. `DASHSCOPE_API_KEY` 是必需项。
2. `DASHSCOPE_MODEL` 默认使用 `kimi-k2.5`。
3. `DASHSCOPE_BASE_URL` 默认使用 DashScope OpenAI-compatible endpoint。
4. API key 只允许保存在本机环境变量中。
5. API key 不允许写入：
   - 源码；
   - README；
   - HANDOFF；
   - demo guide；
   - Markdown 报告；
   - CSV；
   - git commit。

### 5.3 Provider 入口截图建议

建议只截 provider 下拉框，不截任何终端环境变量窗口：


## 8. v0.9.0 演示边界

`v0.9.0` 是 Demo Readiness 和 release hardening，不是新功能扩展阶段。

本版本演示：

- 默认仿真；
- 批量结果 CSV 加载、筛选、排序和导出；
- 批量结果 Markdown 预览和导出；
- 本地规则型 Agent Assistant 分析和导出；
- 可选 DashScope provider 入口和环境变量说明。

本版本不演示：

- 异步 LLM 调用；
- 超时控制；
- 复杂错误提示；
- Qt Graphs；
- GoogleTest 迁移；
- 新增隐私算法；
- 新增任务分配算法。
