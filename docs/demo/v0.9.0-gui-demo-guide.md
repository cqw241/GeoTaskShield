# GeoTaskShield v0.9.0 GUI Demo Guide

This guide is for demonstrating the stable `v0.9.0` GUI workflow. The focus is demo readiness for Simulation, Batch Results, and the default local Agent Assistant. The optional DashScope provider is shown as an entry point only and is not required for the main demo.

## Launch the GUI

From a local debug build:

```powershell
out\build\x64-debug-qt\GeoTaskShield\GeoTaskShieldGui.exe
```

From the Windows release package, run:

```powershell
GeoTaskShieldGui.exe
```

## Main Demo Flow

### 1. Simulation Tab

1. Open the `Simulation` tab.
2. Keep the default parameters.
3. Click `Run Simulation`.
4. Confirm the map shows workers, exposed locations, tasks, and assignment lines.
5. Confirm the metrics panel and log panel update.

### 2. Batch Results Tab

1. Open the `Batch Results` tab.
2. Click `Open CSV`.
3. Select `phase5_batch_results.csv`.
   - In the source tree it is at the repository root.
   - In the release package it is copied next to the executables.
4. Use the privacy filter, for example `Grid Privacy`.
5. Use the algorithm filter, for example `Nearest Greedy`.
6. Change the metric selector, for example:
   - `completionRate`
   - `privacyUtilityRatio`
   - `fairnessIndex`
   - `averagePrivacyLoss`
7. Click table headers to confirm sorting.
   - Numeric columns sort numerically.
   - Text columns sort alphabetically.
8. Select a row and inspect the detail panel.
9. Click `Export Filtered CSV`.
   - Save as `filtered-batch-results-v0.9.0.csv`.
10. Click `Preview Markdown`.
    - Confirm the preview includes the report title, table, row count, and best privacy-utility summary.
11. Click `Export Markdown`.
    - Save as `batch-results-report-v0.9.0.md`.

### 3. Agent Assistant Tab

1. Keep the `Batch Results` CSV loaded.
2. Open the `Agent Assistant` tab.
3. Leave provider set to `Local rule-based`.
4. Enter:

```text
Compare privacy mechanisms for 50 tasks and explain completion rate, privacy utility, privacy loss, and fairness.
```

5. Click `Analyze`.
6. Confirm the parsed intent preview shows workers/tasks if present, requested metrics, and compare intent.
7. Confirm the Markdown analysis includes:
   - best `completionRate`;
   - best `privacyUtilityRatio`;
   - lowest `averagePrivacyLoss`;
   - best `fairnessIndex`;
   - next experiment suggestions.
8. Click `Export Markdown`.
   - Save as `agent-assistant-analysis-v0.9.0.md`.

### 4. Optional DashScope Provider

The `Aliyun Bailian (DashScope)` provider is optional and should not be required for the main demo. Confirm only that the provider selector exists and that documentation explains these environment variables:

```powershell
$env:DASHSCOPE_API_KEY = "<your DashScope API key>"
$env:DASHSCOPE_MODEL = "kimi-k2.5"
$env:DASHSCOPE_BASE_URL = "https://dashscope.aliyuncs.com/compatible-mode/v1"
```

Do not show or store real API keys in screenshots, docs, reports, or commits.
